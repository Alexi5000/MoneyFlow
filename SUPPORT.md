# Support

## Getting help

Use the [GitHub issue tracker](https://github.com/Alexi5000/MoneyFlow/issues) for reproducible local setup failures, documentation corrections, and feature discussions. Include your operating system, Node.js and Python versions, the command you ran, the expected result, and the full non-sensitive error output.

## Scope of support

MoneyFlow is a local-first demo and product foundation. Maintainer support covers the repository’s documented frontend, backend, API-contract, and quality workflows. It does not include financial advice, hosted-service uptime commitments, bank-provider support, recovery of secrets, or handling of real financial records.

## Sensitive concerns

Do **not** place account details, bank tokens, tax information, personal financial records, credentials, or suspected vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md) for private security reporting.

## Collaboration and fork feedback

For Alexi5000-specific product direction, agent-assisted development practice, or controlled automation design, open a scoped issue that states the proposed user outcome and reproducible evidence. See [FORK_POLICY.md](FORK_POLICY.md) for the project’s maintenance boundaries.
